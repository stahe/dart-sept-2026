    6.1. Introduction

    Ce chapitre reprend, sans changement de structure, les trois couches successives de clients construites dans le cours TypeScript, chacune raffinant la précédente : un premier client CLI où tout le calcul reste côté serveur ; un deuxième client CLI où le calcul migre côté client (couche [métier]) ; un troisième client, compilé pour le NAVIGATEUR ; et enfin un client HTML complet, avec ses propres vues. Les quatre s'appuient sur le même serveur NestJS, installé au chapitre précédent.

    // dao1.dart
// Porte Dao1.ts : la couche [dao] (Data Access Object) encapsule tous les
// détails de communication HTTP avec le serveur de calcul de l'impôt (URL,
// méthode, cookie de session) derrière des méthodes métier simples
// (initSession, authentifierUtilisateur, calculerImpot...).
import 'package:dio/dio.dart';

class Dao1 {
  final Dio _dio;
  final String _sessionCookieName;
  String _sessionCookie = '';

  // constructeur - reçoit l'instance Dio à utiliser, comme le script
  // TypeScript recevait l'instance axios en paramètre
  Dao1(this._dio) : _sessionCookieName = "connect.sid";

  // init session
  Future<dynamic> initSession() {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'init-session', 'type': 'json'},
    );
  }

  Future<dynamic> authentifierUtilisateur(String user, String password) {
    return _getRemoteData(
      'main.php',
      method: 'POST',
      queryParameters: {'action': 'authentifier-utilisateur'},
      data: {'user': user, 'password': password},
      contentType: Headers.formUrlEncodedContentType,
    );
  }

  // calcul de l'impôt
  Future<dynamic> calculerImpot(String marie, int enfants, int salaire) {
    return _getRemoteData(
      'main.php',
      method: 'POST',
      queryParameters: {'action': 'calculer-impot'},
      data: {'marié': marie, 'enfants': enfants, 'salaire': salaire},
      contentType: Headers.formUrlEncodedContentType,
    );
  }

  // liste des simulations
  Future<dynamic> listeSimulations() {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'lister-simulations'},
    );
  }

  // supprimer une simulation
  Future<dynamic> supprimerSimulation(int index) {
    return _getRemoteData(
      'main.php',
      method: 'GET',
      queryParameters: {'action': 'supprimer-simulation', 'numéro': index},
    );
  }

  Future<dynamic> _getRemoteData(
    String path, {
    required String method,
    Map<String, dynamic>? queryParameters,
    Object? data,
    String? contentType,
  }) async {
    // pour le cookie de session
    final options = Options(
      method: method,
      contentType: contentType,
      headers: {'Cookie': _sessionCookie},
      validateStatus: (_) => true,
    );
    // exécution de la requête HTTP
    final response = await _dio.request(
      path,
      queryParameters: queryParameters,
      data: data,
      options: options,
    );
    // on récupère le cookie de session s'il existe
    final setCookie = response.headers['set-cookie'];
    if (setCookie != null) {
      for (final entete in setCookie) {
        final resultat = RegExp('^($_sessionCookieName.+?);').firstMatch(entete);
        if (resultat != null) {
          _sessionCookie = resultat.group(1)!;
          break;
        }
      }
    }
    // la réponse du serveur est dans [response.data]
    return response.data;
  }
}

    Commentons ce code :

    • ligne 48 : La couche [dao] (Data Access Object) encapsule tous les détails de communication HTTP (URL, méthode, cookie de session) derrière des méthodes métier simples - [initSession], [authentifierUtilisateur], [calculerImpot], [listeSimulations], [supprimerSimulation] (ligne 57).
    • ligne 15 : [Dao1(this._dio)] reçoit l'instance [Dio] à utiliser en paramètre du constructeur, exactement comme le script TypeScript recevait l'instance [axios].
    • ligne 87 : [_getRemoteData] (privée, préfixe [_]) centralise le suivi manuel du cookie de session ([response.headers['set-cookie']], [RegExp] (ligne 90)) déjà rencontré en dart_dio_03.dart : chaque méthode publique du DAO s'appuie sur cette même méthode privée.

    // metier.dart
// Porte Metier.ts : le calcul de l'impôt, réalisé entièrement côté client
// (dans le navigateur en TypeScript, ici dans le programme Dart), à partir
// des données fiscales brutes obtenues une seule fois du serveur via
// [Dao2.getAdminData] (cf dao2.dart).
class Metier {
  // [dynamic] : la structure exacte des données envoyées par le serveur
  // fiscal (taux, plafonds...) n'est pas documentée ici ; comme en
  // TypeScript, on reste volontairement souple sur ce type
  final Map<String, dynamic> taxAdminData;

  Metier(this.taxAdminData);

  // calcul de l'impôt
  // --------------------------------------------------------------------------
  // marié : oui, non
  // enfants : nombre d'enfants
  // salaire : salaire annuel
  Map<String, dynamic> calculerImpot(String marie, int enfants, num salaire) {
    // calcul de l'impôt avec enfants
    final result1 = _calculerImpot2(marie, enfants, salaire);
    final impot1 = result1['impôt'] as num;
    // calcul de l'impôt sans les enfants
    Map<String, dynamic> result2;
    num impot2;
    num plafondDemiPart;
    if (enfants != 0) {
      result2 = _calculerImpot2(marie, 0, salaire);
      impot2 = result2['impôt'] as num;
      // application du plafonnement du quotient familial
      plafondDemiPart = taxAdminData['plafondQfDemiPart'] as num;
      if (enfants < 3) {
        // plafondDemiPart pour les 2 premiers enfants
        impot2 = impot2 - enfants * plafondDemiPart;
      } else {
        // plafondDemiPart pour les 2 premiers enfants, le double pour les suivants
        impot2 = impot2 - 2 * plafondDemiPart - (enfants - 2) * 2 * plafondDemiPart;
      }
    } else {
      // pas de recalcul de l'impôt
      impot2 = impot1;
      result2 = result1;
    }
    // on prend l'impôt le plus fort dans [impot1, impot2]
    num impot;
    num taux;
    num surcote;
    if (impot1 > impot2) {
      impot = impot1;
      taux = result1['taux'] as num;
      surcote = result1['surcôte'] as num;
    } else {
      surcote = impot2 - impot1 + (result2['surcôte'] as num);
      impot = impot2;
      taux = result2['taux'] as num;
    }
    // calcul d'une éventuelle décôte
    final decote = _getDecote(marie, impot);
    impot -= decote;
    // calcul d'une éventuelle réduction d'impôts
    final reduction = _getReduction(marie, salaire, enfants, impot);
    impot -= reduction;
    // résultat
    return {
      'impôt': impot.floor(),
      'surcôte': surcote,
      'décôte': decote,
      'réduction': reduction,
      'taux': taux,
    };
  }

  // --------------------------------------------------------------------------
  Map<String, dynamic> _calculerImpot2(String marie, int enfants, num salaire) {
    // nombre de parts
    marie = marie.toLowerCase();
    num nbParts;
    if (marie == "oui") {
      nbParts = enfants / 2 + 2;
    } else {
      nbParts = enfants / 2 + 1;
    }
    // 1 part par enfant à partir du 3ième
    if (enfants >= 3) {
      // une demi-part de + pour chaque enfant à partir du 3ième
      nbParts += 0.5 * (enfants - 2);
    }
    // revenu imposable
    final revenuImposable = _getRevenuImposable(salaire);
    // surcôte
    num surcote = (revenuImposable - 0.9 * salaire).floor();
    // pour des pbs d'arrondi
    if (surcote < 0) {
      surcote = 0;
    }
    // quotient familial
    final quotient = revenuImposable / nbParts;
    // calcul de l'impôt
    final List<num> limites = List<num>.from(taxAdminData['limites'] as List);
    final List<num> coeffR = List<num>.from(taxAdminData['coeffR'] as List);
    final List<num> coeffN = List<num>.from(taxAdminData['coeffN'] as List);
    // est mis à la fin de la liste [limites] pour arrêter la boucle qui suit
    limites[limites.length - 1] = quotient;
    // recherche du taux d'imposition
    var i = 0;
    while (quotient > limites[i]) {
      i++;
    }
    // du fait qu'on a placé quotient à la fin de limites, la boucle
    // précédente ne peut déborder de la liste limites
    // maintenant on peut calculer l'impôt
    final impot = (revenuImposable * coeffR[i] - nbParts * coeffN[i]).floor();
    // résultat
    return {'impôt': impot, 'surcôte': surcote, 'taux': coeffR[i]};
  }

  // revenuImposable = salaireAnnuel - abattement (l'abattement a un min et un max)
  num _getRevenuImposable(num salaire) {
    // abattement de 10% du salaire
    num abattement = 0.1 * salaire;
    // cet abattement ne peut dépasser abattementDixPourCentMax
    final abattementMax = taxAdminData['abattementDixPourCentMax'] as num;
    if (abattement > abattementMax) {
      abattement = abattementMax;
    }
    // l'abattement ne peut être inférieur à abattementDixPourcentMin
    final abattementMin = taxAdminData['abattementDixPourcentMin'] as num;
    if (abattement < abattementMin) {
      abattement = abattementMin;
    }
    // revenu imposable
    final revenuImposable = salaire - abattement;
    return revenuImposable.floor();
  }

  // calcule une décôte éventuelle
  num _getDecote(String marie, num impots) {
    // au départ, une décôte nulle
    num decote = 0;
    // montant maximal d'impôt pour avoir la décôte
    final plafondImpotPourDecote = marie == "oui"
        ? taxAdminData['plafondImpotCouplePourDecote'] as num
        : taxAdminData['plafondImpotCelibatairePourDecote'] as num;
    if (impots < plafondImpotPourDecote) {
      // montant maximal de la décôte
      final plafondDecote = marie == "oui"
          ? taxAdminData['plafondDecoteCouple'] as num
          : taxAdminData['plafondDecoteCelibataire'] as num;
      // décôte théorique
      decote = plafondDecote - 0.75 * impots;
      // la décôte ne peut dépasser le montant de l'impôt
      if (decote > impots) {
        decote = impots;
      }
      // pas de décôte < 0
      if (decote < 0) {
        decote = 0;
      }
    }
    // résultat - ceil() est l'équivalent Dart de Math.ceil()
    return decote.ceil();
  }

  // calcule une réduction éventuelle
  num _getReduction(String marie, num salaire, int enfants, num impots) {
    // le plafond des revenus pour avoir droit à la réduction de 20%
    num plafondRevenuPourReduction = marie == "oui"
        ? taxAdminData['plafondRevenusCouplePourReduction'] as num
        : taxAdminData['plafondRevenusCelibatairePourReduction'] as num;
    final valeurReducDemiPart = taxAdminData['valeurReducDemiPart'] as num;
    plafondRevenuPourReduction += enfants * valeurReducDemiPart;
    if (enfants > 2) {
      plafondRevenuPourReduction += (enfants - 2) * valeurReducDemiPart;
    }
    // revenu imposable
    final revenuImposable = _getRevenuImposable(salaire);
    // réduction
    num reduction = 0;
    if (revenuImposable < plafondRevenuPourReduction) {
      // réduction de 20%

    6.4.1. Évolution de l'outillage depuis 2019

    Ce troisième client reprend le même duo [dao]/[métier] que le client HTTP 2, mais COMPILÉ POUR LE NAVIGATEUR plutôt qu'exécuté en ligne de commande. Côté TypeScript, cette compilation exige webpack et babel, ainsi que des polyfills ([core-js/stable], [regenerator-runtime/runtime]) pour que le code moderne fonctionne sur d'anciens navigateurs. Côté Dart, le SDK fournit lui-même son compilateur web ([dart compile js]) : aucun polyfill n'est nécessaire, [Future]/[async]/[await], les records, les patterns... sont compilés directement vers du JavaScript équivalent, quelle que soit la cible.

// Le résultat d'un calcul d'impôt, tel que rendu par metier.dart, complété
// par les paramètres saisis. Porte l'interface [Simulation] de Vues.ts.
//
// [NOUVEAU, Dart 3] on utilise ici un RECORD nommé (cf
// dart-fondamentaux/dart3/dart3_01_records.dart) plutôt qu'une classe : un
// simple alias de type [typedef], sans constructeur ni fichier séparé à
// écrire, pour une donnée qui n'est qu'un simple "sac" de champs, sans
// aucun comportement associé - exactement l'esprit de l'interface
// TypeScript d'origine.
//
// [NOTE sur les noms de champs] contrairement à TypeScript/JavaScript, où
// un identifiant peut contenir des lettres accentuées ('marié', 'impôt' -
// utilisées tout du long dans le cours d'origine), Dart réserve les
// identifiants aux lettres ASCII : les accents ne sont possibles que dans
// les CHAÎNES DE CARACTÈRES (ce que fait metier.dart, dont les clés de Map
// 'impôt', 'décôte'... restent accentuées), jamais dans un nom de
// variable, de champ, de classe ou de record. C'est pourquoi ce cours
// utilise systématiquement des noms sans accent (marie, impot, decote...)
// pour tout ce qui est un IDENTIFIANT Dart.
typedef Simulation = ({
  String marie,
  int enfants,
  num salaire,
  num impot,
  num surcote,
  num decote,
  num reduction,
  num taux,
});

// Porte Vues.ts : construction des vues (DOM) de l'application - vue
// authentification, vue calcul de l'impôt, vue liste des simulations. Ce
// module ne fait aucun appel réseau : il construit le DOM et délègue les
// actions de l'utilisateur à des fonctions de rappel fournies par le
// contrôleur (voir app_html.dart).
//
// [choix technique] on utilise ici [package:web] (pub.dev/packages/web),
// le remplaçant moderne de l'ancien dart:html : il expose une API DOM très
// proche du DOM standard utilisé par Vues.ts (document.createElement,
// .textContent, .addEventListener...). Une différence de surface à
// connaître : un gestionnaire d'événement Dart (une simple fonction) doit
// être converti en fonction JavaScript avec [.toJS] (extension de
// dart:js_interop) avant d'être passé à [addEventListener] - le "pont"
// entre le monde Dart et le monde JavaScript, rendu explicite, là où
// TypeScript n'a besoin d'aucune conversion (tout y est déjà du
// JavaScript).
import 'dart:js_interop';
import 'package:web/web.dart' as web;
import 'simulation.dart';

// callbacks de la vue [authentification] - [différence avec TypeScript]
// une interface TypeScript de callbacks se traduit naturellement en un
// RECORD de fonctions en Dart (cf simulation.dart) : plus léger qu'une
// classe, pour un simple groupe de fonctions
typedef CallbacksAuthentification = ({void Function(String user, String password) onValider});

typedef CallbacksCalcul = ({
  void Function(String marie, int enfants, int salaire) onValider,
  void Function() onListe,
  void Function() onFinSession,
});

typedef CallbacksListe = ({
  void Function(int numero) onSupprimer,
  void Function() onCalcul,
  void Function() onFinSession,

class Vues {
  final web.HTMLElement racine;
  late web.HTMLDivElement _bandeau;
  late web.HTMLDivElement _menu;
  late web.HTMLDivElement _contenu;

  // construit la structure fixe de la page (bandeau + zone menu/contenu) à
  // l'intérieur de l'élément [racine]
  Vues(this.racine) {
    // [ATTENTION] contrairement aux propriétés DOM ordinaires (textContent,
    // value...), le setter [innerHTML] de package:web attend un [JSAny], pas
    // un [String] Dart brut - une particularité de sa génération liée à
    // l'attribut WebIDL [LegacyNullToEmptyString] du DOM standard : il faut
    // donc systématiquement convertir avec [.toJS].
    racine.innerHTML = ''.toJS;

    _bandeau = _div()..className = 'bandeau';
    final logo = _div()..className = 'logo';
    logo.innerHTML = _logoSvg.toJS;
    final titre = web.document.createElement('h1') as web.HTMLHeadingElement;
    titre.textContent = 'Calculez votre impôt';
    _bandeau
      ..appendChild(logo)
      ..appendChild(titre);

    final corps = _div()..className = 'corps';
    _menu = _div()..className = 'menu';
    _contenu = _div()..className = 'contenu';
    corps
      ..appendChild(_menu)
      ..appendChild(_contenu);

    racine
      ..appendChild(_bandeau)
      ..appendChild(corps);
  }

  // --------------------------------------------------------------------
  // outils de construction du DOM
  // --------------------------------------------------------------------

  web.HTMLDivElement _div() => web.document.createElement('div') as web.HTMLDivElement;

  void _viderMenu() {
    _menu.innerHTML = ''.toJS;
    _menu.style.display = 'none';
    _contenu.classList.add('pleine-largeur');
  }

  web.HTMLAnchorElement _lienMenu(String texte, void Function() onClick) {
    final a = web.document.createElement('a') as web.HTMLAnchorElement;
    a.textContent = texte;
    a.addEventListener('click', ((web.Event event) => onClick()).toJS);
    return a;
  }

  void _afficherMenu(List<web.HTMLAnchorElement> liens) {
    _menu.innerHTML = ''.toJS;
    _menu.style.display = '';
    _contenu.classList.remove('pleine-largeur');
    for (final lien in liens) {
      _menu.appendChild(lien);
    }
  }

  web.HTMLElement? _banniereErreur(String? message) {
    if (message == null) return null;
    final div = _div()..className = 'erreur';
    div.textContent = message;
    return div;
  }

  // une ligne de formulaire [label + champ texte/mot de passe/nombre]
  (web.HTMLDivElement ligne, web.HTMLInputElement input) _ligneChamp(
    String libelle,
    String type,
    String valeurInitiale, {
    String? aide,
  }) {
    final ligne = _div()..className = 'ligne-champ';
    final label = web.document.createElement('label') as web.HTMLLabelElement;
    label.textContent = libelle;
    final champ = _div()..className = 'champ';
    final input = web.document.createElement('input') as web.HTMLInputElement;
    input.type = type;
    input.value = valeurInitiale;
    if (type == 'number') {
      input.min = '0';
    }
    champ.appendChild(input);
    if (aide != null) {
      final div = _div()..className = 'aide';
      div.textContent = aide;
      champ.appendChild(div);
    }
    ligne
      ..appendChild(label)
      ..appendChild(champ);
    return (ligne, input);
  }

  // --------------------------------------------------------------------
  // vue [authentification]
  // --------------------------------------------------------------------
  void vueAuthentification(String? erreur, CallbacksAuthentification callbacks) {
    _viderMenu();
    _contenu.innerHTML = ''.toJS;

    final titre = _div()
      ..className = 'titre-section'
      ..textContent = 'Veuillez vous authentifier';
    _contenu.appendChild(titre);

    final banniere = _banniereErreur(erreur);
    if (banniere != null) _contenu.appendChild(banniere);

    final champUser = _ligneChamp("Nom d'utilisateur", 'text', 'admin');
    final champPassword = _ligneChamp('Mot de passe', 'password', '');
    _contenu
      ..appendChild(champUser.$1)
      ..appendChild(champPassword.$1);

    final bouton = web.document.createElement('button') as web.HTMLButtonElement;
    bouton.textContent = 'Valider';
    bouton.addEventListener(
      'click',
      ((web.Event event) {
        callbacks.onValider(champUser.$2.value.trim(), champPassword.$2.value);
      }).toJS,
    );
    _contenu.appendChild(bouton);
  }

  // --------------------------------------------------------------------
  // vue [calcul de l'impôt]
  // --------------------------------------------------------------------
  void vueCalcul(Simulation? resultat, String? erreur, CallbacksCalcul callbacks) {
    _afficherMenu([
      _lienMenu('Liste des simulations', callbacks.onListe),
      _lienMenu('Fin de session', callbacks.onFinSession),
    ]);

    _contenu.innerHTML = ''.toJS;

    final titre = _div()
      ..className = 'titre-section'
      ..textContent = 'Remplissez le formulaire ci-dessous puis validez-le';
    _contenu.appendChild(titre);

    final banniere = _banniereErreur(erreur);
    if (banniere != null) _contenu.appendChild(banniere);

    // ligne des radios [marié(e)]
    final ligneMarie = _div()..className = 'ligne-champ';
    final labelMarie = web.document.createElement('label') as web.HTMLLabelElement;
    labelMarie.textContent = 'Etes-vous marié(e) ou pacsé(e) ?';
    final champMarie = _div()..className = 'champ radios';

    final radioOui = web.document.createElement('input') as web.HTMLInputElement;
    radioOui.type = 'radio';
    radioOui.name = 'marie';
    radioOui.value = 'oui';
    radioOui.checked = true;
    final labelOui = web.document.createElement('label') as web.HTMLLabelElement;
    labelOui.appendChild(radioOui);
    labelOui.appendChild(web.document.createTextNode(' Oui'));

    final radioNon = web.document.createElement('input') as web.HTMLInputElement;
    radioNon.type = 'radio';
    radioNon.name = 'marie';
    radioNon.value = 'non';
    final labelNon = web.document.createElement('label') as web.HTMLLabelElement;
    labelNon.appendChild(radioNon);
    labelNon.appendChild(web.document.createTextNode(' Non'));

    champMarie
      ..appendChild(labelOui)
      ..appendChild(labelNon);
    ligneMarie
      ..appendChild(labelMarie)
      ..appendChild(champMarie);
    _contenu.appendChild(ligneMarie);

    final champEnfants = _ligneChamp("Nombre d'enfants à charge", 'number', '0');
    _contenu.appendChild(champEnfants.$1);

    final champSalaire = _ligneChamp(
      'Salaire annuel',
      'number',
      '',
      aide: "Arrondissez à l'euro inférieur",
    );
    _contenu.appendChild(champSalaire.$1);

    final bouton = web.document.createElement('button') as web.HTMLButtonElement;
    bouton.textContent = 'Valider';
    bouton.addEventListener(
      'click',
      ((web.Event event) {
        final marie = radioOui.checked ? 'oui' : 'non';
        final enfants = int.tryParse(champEnfants.$2.value) ?? 0;
        final salaire = int.tryParse(champSalaire.$2.value) ?? 0;
        callbacks.onValider(marie, enfants, salaire);
      }).toJS,
    );
    _contenu.appendChild(bouton);

    // résultat de la dernière simulation (encadré vert), s'il y en a un
    if (resultat != null) {
      final box = _div()..className = 'resultat';
      final tauxPourcent = (resultat.taux * 100).round();
      box.innerHTML = ("Montant de l'impôt : ${resultat.impot} euros<br>"
              "Décôte : ${resultat.decote} euros<br>"
              "Réduction : ${resultat.reduction} euros<br>"
              "Surcôte : ${resultat.surcote} euros<br>"
              "Taux d'imposition : $tauxPourcent %")
          .toJS;
      _contenu.appendChild(box);
    }
  }

  // --------------------------------------------------------------------
  // vue [liste des simulations]
  // --------------------------------------------------------------------
  void vueListe(List<Simulation> simulations, String? erreur, CallbacksListe callbacks) {
    _afficherMenu([
      _lienMenu("Calcul de l'impôt", callbacks.onCalcul),
      _lienMenu('Fin de session', callbacks.onFinSession),
    ]);

    _contenu.innerHTML = ''.toJS;

    final titre = _div()
      ..className = 'titre-section'
      ..textContent = 'Liste de vos simulations';
    _contenu.appendChild(titre);

    final banniere = _banniereErreur(erreur);
    if (banniere != null) _contenu.appendChild(banniere);

    if (simulations.isEmpty) {
      final vide = _div()
        ..className = 'simulations-vide'
        ..textContent = 'Aucune simulation enregistrée.';
      _contenu.appendChild(vide);
      return;
    }

    final table = web.document.createElement('table') as web.HTMLTableElement;
    table.className = 'simulations';
    final thead = web.document.createElement('thead') as web.HTMLTableSectionElement;
    thead.innerHTML = ("<tr><th>#</th><th>Marié</th><th>Nombre d'enfants</th>"
            "<th>Salaire annuel</th><th>Montant impôt</th><th>Surcôte</th>"
            "<th>Décôte</th><th>Réduction</th><th>Taux</th><th></th></tr>")
        .toJS;
    table.appendChild(thead);

    final tbody = web.document.createElement('tbody') as web.HTMLTableSectionElement;
    for (var numero = 0; numero < simulations.length; numero++) {
      final simulation = simulations[numero];
      final tr = web.document.createElement('tr') as web.HTMLTableRowElement;
      final tauxPourcent = (simulation.taux * 100).round();
      tr.innerHTML = ("<td>$numero</td>"
              "<td>${simulation.marie}</td>"
              "<td>${simulation.enfants}</td>"
              "<td>${simulation.salaire}</td>"
              "<td>${simulation.impot}</td>"
              "<td>${simulation.surcote}</td>"
              "<td>${simulation.decote}</td>"
              "<td>${simulation.reduction}</td>"
              "<td>$tauxPourcent %</td>")
          .toJS;
      final tdSupprimer = web.document.createElement('td') as web.HTMLTableCellElement;
      final lienSupprimer = web.document.createElement('a') as web.HTMLAnchorElement;
      lienSupprimer.className = 'supprimer';
      lienSupprimer.textContent = 'Supprimer';
      lienSupprimer.addEventListener(
        'click',
        ((web.Event event) => callbacks.onSupprimer(numero)).toJS,
      );
      tdSupprimer.appendChild(lienSupprimer);
      tr.appendChild(tdSupprimer);
      tbody.appendChild(tr);
    }
    table.appendChild(tbody);
    _contenu.appendChild(table);
  }
}

// Comme main3.dart, ce client ne sollicite le serveur NestJS que pour trois
// actions : [init-session], [authentifier-utilisateur] et [get-admindata].
// Une fois les données fiscales (taux, plafonds...) récupérées avec
// [get-admindata], c'est la couche [métier] qui calcule l'impôt dans le
// navigateur, sans nouvel appel réseau. La liste des simulations est elle
// aussi conservée uniquement dans le navigateur (champ [simulations]),
// exactement comme le fait main3.dart avec sa variable locale
// [simulations] (`simulations.add(...)`, `simulations.removeAt(...)`).
import 'dart:js_interop';
import 'package:http/browser_client.dart';
import 'dao3.dart';
import 'metier.dart';
import 'simulation.dart';
import 'vues.dart';
import 'package:web/web.dart' as web;

class AppHtml {
  final Dao3 dao;
  final Vues vues;
  // couche [métier] : n'existe qu'une fois les données fiscales récupérées
  // (après une authentification réussie) - cf [initialiserMetier]. Un
  // champ NULLABLE (Metier?), pas un champ tardif ([late]) : contrairement
  // à Vues.ts où [métier?: Métier] reste simplement "undefined" tant qu'il
  // n'est pas affecté, un champ [late] Dart lèverait une erreur si on le
  // LISAIT avant affectation (ce que fait justement [finSession] en le
  // remettant à néant) - le type nullable est donc ici le bon choix, pas
  // seulement une question de style.
  Metier? _metier;
  // liste des simulations déjà calculées, conservée dans le navigateur
  List<Simulation> _simulations = [];

  // [différence avec TypeScript] AppHtml.ts configure une instance GLOBALE
  // d'axios (axios.defaults.timeout/baseURL/withCredentials) puis la confie
  // au Dao. Ici, [BrowserClient] (package:http/browser_client.dart, déjà
  // rencontré dans main3.dart) porte l'équivalent de
  // "axios.defaults.withCredentials = true" ; il n'y a pas d'équivalent
  // direct à un "timeout global" sur http.Client - on l'appliquerait au cas
  // par cas avec `.timeout(Duration(...))` sur chaque appel, comme dans le
  // chapitre [http] (dart_fetch_01.dart).
  AppHtml()
      : dao = Dao3(
          BrowserClient()..withCredentials = true,
          'http://localhost:3000',
        ),
        vues = Vues(web.document.getElementById('app') as web.HTMLElement);

  // point d'entrée de l'application
  Future<void> demarrer() async {
    try {
      // init session - obligatoire avant toute autre action (cf main.php)
      final reponse = await dao.initSession() as Map<String, dynamic>;
      if (reponse['état'] != 700) {
        vues.vueAuthentification(
          _formaterErreur(reponse['réponse']),
          (onValider: (user, password) => _authentifier(user, password)),
        );
        return;
      }
    } catch (erreur) {
      vues.vueAuthentification(
        "Impossible de contacter le serveur ($erreur)",
        (onValider: (user, password) => _authentifier(user, password)),
      );
      return;
    }
    // session initialisée : on affiche l'authentification
    _afficherAuthentification();
  }

  // --------------------------------------------------------------------
  // vue [authentification]
  // --------------------------------------------------------------------
  void _afficherAuthentification([String? erreur]) {
    vues.vueAuthentification(
      erreur,
      (onValider: (user, password) => _authentifier(user, password)),
    );
  }

  Future<void> _authentifier(String user, String password) async {
    try {
      final reponse = await dao.authentifierUtilisateur(user, password)
          as Map<String, dynamic>;
      if (reponse['état'] == 200) {
        // authentification réussie : comme dans main3.dart, on récupère
        // maintenant, une bonne fois pour toutes, les données fiscales
        // nécessaires à la couche [métier]
        await _initialiserMetier();
      } else {
        // échec (mauvais login/mot de passe, ou paramètres manquants)
        _afficherAuthentification(_formaterErreur(reponse['réponse']));
      }
    } catch (erreur) {
      _afficherAuthentification("Impossible de contacter le serveur ($erreur)");
    }
  }

  // récupère les données de l'administration fiscale et instancie la
  // couche [métier] avec ces données - un seul appel serveur pour toute la
  // session, exactement comme main3.dart
  Future<void> _initialiserMetier() async {
    try {
      final reponse = await dao.getAdminData() as Map<String, dynamic>;
      if (reponse['état'] == 1000) {
        _metier = Metier(reponse['réponse'] as Map<String, dynamic>);
        // nouvelle session de travail : on repart d'une liste vide
        _simulations = [];
        _afficherCalcul();
      } else {
        _afficherAuthentification(_formaterErreur(reponse['réponse']));
      }
    } catch (erreur) {
      _afficherAuthentification("Impossible de contacter le serveur ($erreur)");
    }
  }

  // --------------------------------------------------------------------
  // vue [calcul de l'impôt]
  // --------------------------------------------------------------------
  void _afficherCalcul([Simulation? resultat, String? erreur]) {
    vues.vueCalcul(
      resultat,
      erreur,
      (
        onValider: (marie, enfants, salaire) =>
            _calculer(marie, enfants, salaire),
        onListe: () => _afficherListe(),
        onFinSession: () => _finSession(),
      ),
    );
  }

  // calcul de l'impôt fait entièrement dans le navigateur (couche
  // [métier]) : aucun appel au serveur, contrairement à la première version
  // de ce client (client http 1 / client http 2)
  void _calculer(String marie, int enfants, int salaire) {
    // _metier a forcément été initialisé : on n'arrive sur la vue [calcul]
    // qu'après _initialiserMetier (le [!] est donc sûr ici, comme le [!]
    // de TypeScript sur [this.métier!])
    final resultat = _metier!.calculerImpot(marie, enfants, salaire);
    // [différence avec TypeScript] Vues.ts construit la simulation avec un
    // simple spread d'objet : `{ marié, enfants, salaire, ...résultat }`.
    // Ici, [Simulation] est un RECORD (simulation.dart), pas une Map : un
    // record ne peut pas être "complété" par spread à partir d'une Map, et
    // ses champs sont nommés SANS accent (impot, surcote...) alors que
    // [resultat], renvoyé par metier.dart, est une Map dont les clés
    // GARDENT les accents ('impôt', 'surcôte'..., cf metier.dart). On
    // reconstruit donc le record champ par champ - un peu plus verbeux
    // qu'un spread, mais entièrement vérifié par le compilateur (un champ
    // oublié ou mal typé est une erreur de compilation, pas une surprise à
    // l'exécution).
    final Simulation simulation = (
      marie: marie,
      enfants: enfants,
      salaire: salaire,
      impot: resultat['impôt'] as num,
      surcote: resultat['surcôte'] as num,
      decote: resultat['décôte'] as num,
      reduction: resultat['réduction'] as num,
      taux: resultat['taux'] as num,
    );
    // mémorisation dans le navigateur (comme `simulations.add(...)` dans
    // main3.dart)
    _simulations.add(simulation);
    _afficherCalcul(simulation);
  }

  // --------------------------------------------------------------------
  // vue [liste des simulations]
  // --------------------------------------------------------------------
  // plus aucun appel serveur ici : la liste est déjà entièrement dans
  // [_simulations]
  void _afficherListe([String? erreur]) {
    vues.vueListe(
      _simulations,
      erreur,
      (
        onSupprimer: (numero) => _supprimer(numero),
        onCalcul: () => _afficherCalcul(),
        onFinSession: () => _finSession(),
      ),
    );
  }

  void _supprimer(int numero) {
    // suppression locale de [_simulations], comme
    // `simulations.removeAt(numéro)` dans main3.dart - toujours aucun
    // appel serveur
    _simulations.removeAt(numero);
    _afficherListe();
  }

  // --------------------------------------------------------------------
  // fin de session
  // --------------------------------------------------------------------
  void _finSession() {
    // fin de session côté client uniquement : on oublie la couche [métier]
    // (donc les données fiscales) et les simulations déjà calculées, puis
    // on revient à l'écran d'authentification. Ce client n'a pas besoin de
    // solliciter le serveur pour cela.
    _metier = null;
    _simulations = [];
    _afficherAuthentification();
  }

  // --------------------------------------------------------------------
  // met en forme le champ [réponse] d'une réponse d'erreur du serveur, qui
  // est soit une chaîne, soit une liste de chaînes (cf contrôleurs PHP)
  // --------------------------------------------------------------------
  String _formaterErreur(Object? reponse) {
    if (reponse is List) {
      return reponse.join(' ; ');
    }
    return '$reponse';
  }
}

// exécution - [différence avec TypeScript] le gestionnaire d'événement
// passé à addEventListener doit être converti en fonction JavaScript avec
// [.toJS] (cf vues.dart) ; ce n'est là que la version "point d'entrée" de
// la même règle.
void main() {
  web.window.addEventListener(
    'DOMContentLoaded',
    ((web.Event event) {
      AppHtml().demarrer();
    }).toJS,
  );
}

    Commentons ce code :

    • lignes 46-51 : [AppHtml() : dao = Dao3(BrowserClient()..withCredentials = true, ...), vues = Vues(...)] : la construction du DAO et des VUES dans une LISTE D'INITIALISATION de constructeur - même idée que le constructeur TypeScript, avec la syntaxe [: champ1 = ..., champ2 = ...] propre à Dart.
    • ligne 34 : [Metier? _metier;] : un champ NULLABLE, là où AppHtml.ts utilisait [métier?: Métier] - la même idée («pas encore initialisé»), avec le même opérateur [!] à l'usage pour affirmer qu'il est bien renseigné à un point donné du code.
    • lignes 158-162 : [final Simulation simulation = (marie: marie, ..., impot: resultat['impôt'] as num, ...);] : contrairement au simple spread [{ marié, enfants, salaire, ...résultat }] de Vues.ts, un RECORD ne peut pas être complété par spread à partir d'une [Map] - le record est donc reconstruit CHAMP PAR CHAMP, un peu plus verbeux mais entièrement vérifié par le compilateur.
    • lignes 229-233 : [web.window.addEventListener('DOMContentLoaded', ((web.Event event) { AppHtml().demarrer(); }).toJS);] : le même point d'entrée que AppHtml.ts, avec la même conversion [.toJS] du callback que dans vues.dart.

    6.6. Conclusion

    Les quatre clients de ce chapitre illustrent, avec Dart, exactement la même progression qu'avec TypeScript : du calcul côté serveur au calcul côté client, puis du script CLI au client web complet. Les différences systématiques à retenir sont le suivi manuel du cookie de session (nécessaire en CLI, superflu dans un navigateur), la conversion [.toJS] imposée par [dart:js_interop] pour franchir la frontière Dart/JavaScript dans les vues, et l'absence totale de polyfills à la compilation web - un avantage net de l'outillage Dart sur la chaîne webpack/babel.
